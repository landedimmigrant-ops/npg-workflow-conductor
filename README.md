# NPG Workflow Conductor

A polished single-page walkthrough tool for reviewing the NPG Living Lab workflow.

The tool helps reviewers move through each workflow step, inspect timing and dependencies, mark readiness, capture comments/questions/suggestions, and send structured feedback through GitHub Issues.

## Website

When published with GitHub Pages, the site will be available at:

https://landedimmigrant-ops.github.io/npg-workflow-conductor/

## Feedback

The `Feedback` button opens a prefilled GitHub Issue for:

https://github.com/landedimmigrant-ops/npg-workflow-conductor/issues

Reviewers can inspect the generated issue body before submitting it on GitHub.

## Local Use

Open `index.html` directly in a browser. No build step is required.
